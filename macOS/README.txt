币安浮动行情 | macOS 11 Big Sur 及以上（Apple 芯片和 Intel 都支持）

这是原生 macOS 版（Swift / AppKit），需要在 Mac 上编译一次：
1. 把整个 macOS 文件夹拷到 Mac 上。
2. 如果没装过 Xcode 命令行工具，先在“终端”运行：xcode-select --install
3. 在终端进入这个文件夹，运行：bash build.sh
   最后看到 “PASS” 和 “完成” 就说明编译和自检都通过了。
4. 运行：open MarketFloat.app（也可以把 MarketFloat.app 拖到“应用程序”文件夹）。

功能与 Windows 版一致：
- 无边框悬浮面板，默认在所有桌面空间和全屏应用上方显示。
- 背景透明度 7 档（≡ 或右键 → 背景透明度），中间几档使用 macOS 原生毛玻璃模糊。
- 按住面板任意位置拖动，拖右下角点阵调整大小，双击面板或按 F2 切换普通／极简模式。
- 触控板或滚轮滚动、↑／↓、Page Up／Page Down 翻看报价。
- 币安 WebSocket 实时推送为主、REST 轮询备用；显示 24 小时涨跌幅，价格按合约最小变动价位固定小数位，变动时短暂高亮（涨绿跌红）。
- ≡ → 自选品种：搜索并勾选币安 USDT 永续合约（加密货币、贵金属、美股／ETF）。
- 自选、位置、大小、透明度、置顶设置会自动保存。
- 点 × 或 ⌘Q 退出；“隐藏”后点程序坞图标恢复。
