币安浮动行情 | Windows 10 / 11

解压后双击 MarketFloat.exe。更新前请关闭旧版。无需安装、登录或配置 API 密钥。
在 ≡ → 自选品种搜索代码或名称并勾选。内置 2026-11-16 的币安目录，含 721 个加密货币、贵金属和美股／ETF 的 USDT 永续合约，包括 SNDKUSDT（闪迪）。连上币安会自动更新目录。
拖动右下角的点阵缩放，滚动鼠标滚轮、按 ↑／↓ 或 Page Up／Page Down 查看其他报价。
按住面板任意位置拖动窗口，靠近屏幕边缘会自动吸附。≡（或右键）→ 背景透明度：不透明到完全透明共 7 档，默认“透明 45%”的磨砂玻璃效果。完全透明时文字带柔和描边，鼠标移入面板会略微加深背景，便于阅读和拖动。
点 − 或按 F2 切换极简模式，点 + 恢复普通模式。价格变动时短暂高亮（涨绿跌红）。
程序会记住自选、位置、透明度和窗口大小。

报价使用币安 USDT 永续合约最新成交价，以 WebSocket 实时推送为主；推送中断时自动改用 REST 每秒轮询，并在后台重连。每行显示 24 小时涨跌幅，价格按合约最小变动价位固定小数位，数字不再跳动。断线时保留最近一次价格，未收到价格时显示 —。
没有报价时，点 ≡ → 行情连接诊断，查看 WebSocket 和 REST 的连接状态。内置目录只包含合约信息。
程序只运行一个实例，再次双击会把已打开的面板调到前面。支持多显示器不同缩放比例。
macOS 版在 macOS 文件夹里，使用方法见其中的 README.txt。
